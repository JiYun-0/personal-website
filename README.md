# 纪云的个人网站

一个简洁的个人主页，部署在 GitHub Pages 上。

## 技术栈

- 纯 HTML / CSS / JavaScript
- 无框架依赖，轻量快速
- GitHub Pages 托管

## 本地运行

```bash
# 直接用浏览器打开即可
open index.html
```

或使用简单的 HTTP 服务器：

```bash
npx serve .
```

## 部署到 GitHub Pages

1. 将代码推送到 GitHub 仓库
2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支，根目录 `/`
4. 保存后等待几分钟，网站即可访问

## 自定义

- 修改 `index.html` 中的个人信息
- 修改 `style.css` 中的颜色主题
- 添加自己的项目到项目展示区
